# Contributing to Awesome Kindle

Thanks for helping make this index better! 🐧

This guide keeps contributions consistent and high-quality. It applies to both the [English](README_EN.md) and [中文](README.md) docs.

---

## What we accept

- ✅ **Open-source / free** Kindle tools, jailbreaks, apps, plugins, firmware utilities, docs
- ✅ Working **official links** (repository, wiki, release page)
- ✅ Corrections: outdated firmware ranges, archived projects, dead links
- ✅ New jailbreak methods, new homebrew, new guides

## What we do **not** accept

- ❌ Pirated books, cracked firmware, or "free ebook" download sites
- ❌ Closed-source commercial software or paid-only tools (unless there is a meaningful free tier)
- ❌ Referral / affiliate links, SEO spam, or link shorteners
- ❌ Content that requires bypassing paywalls or DRM

---

## How to contribute

1. **Fork** the repository and create a branch:
   ```bash
   git checkout -b feat/add-some-tool
   ```
2. **Add your entry** in the right section of **both** `README.md` and `README_EN.md`.
   - Keep the existing table format and column alignment.
   - Use the format: `| **Name** | Short description | [link](https://…) |`
   - One sentence per description; no marketing fluff.
3. **Verify your link** returns HTTP 200 and points to the official source.
4. **Commit** with a clear message:
   ```
   feat: add <tool> to <category>
   fix: update <jailbreak> firmware range
   ```
5. **Open a Pull Request** and briefly explain the change.

---

## Entry quality checklist

- [ ] Open-source / free and actively usable
- [ ] Official, reachable link (no shorteners)
- [ ] Correct category and alphabetical-ish placement within the table
- [ ] Description ≤ ~120 characters, factual, no hype
- [ ] Added to **both** language versions
- [ ] No duplicate of an existing entry

---

## Reporting a broken link or outdated info

Open an issue using the **Broken link / outdated info** template, or just send a PR — both are welcome.

## 中文摘要

- 只收录**开源 / 免费**且**可用**的 Kindle 工具、越狱、应用、固件工具与文档。
- 每条都要有**官方可访问链接**，并在 `README.md` 与 `README_EN.md` **两个版本同步添加**。
- 拒绝盗版书籍、破解固件、闭源付费软件、返利 / 短链。
- 表格保持原有格式；描述一句话、客观、不超过约 120 字。
- 提交 PR 时说明改动原因；链接失效或信息过时也欢迎直接提 Issue / PR。
