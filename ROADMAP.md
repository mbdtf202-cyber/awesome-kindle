# Roadmap

Where **Awesome Kindle** is headed. PRs and suggestions welcome.

## ✅ Done

- [x] Bilingual README (English / 简体中文), structurally identical
- [x] Full jailbreak compatibility matrix (model + firmware)
- [x] Device matrix incl. 2025–2026 models
- [x] Post-jailbreak toolkit, apps & games, developer resources
- [x] Legal content sources (ebooks, comics, audiobooks, papers) + pipeline
- [x] Quick start, why-jailbreak, device-ID, glossary
- [x] Hand-drawn SVG banner + 1280×640 social preview
- [x] Link-check CI (lychee), issue/PR templates, contributing & code of conduct
- [x] Machine-readable index (`data/resources.json`) + generator
- [x] Searchable static site (`docs/`) — now **live on GitHub Pages**

## 🚧 Next

- [ ] Per-jailbreak step-by-step docs pages (`docs/jailbreaks/*.md`)
- [ ] Per-tool "how to install & use" mini-guides
- [ ] Screenshots / GIFs for the most popular tools
- [ ] Auto-refresh `resources.json` on a schedule and on each release
- [ ] More languages (日本語 / 한국어)
- [ ] A curated "starter pack" checklist for first-time jailbreakers

## 💡 Ideas / wishlist

- [ ] Windows/macOS one-click helper wrappers (where upstream allows)
- [ ] Offline single-file HTML export of the whole index
- [ ] Community showcase of Kindle setups

> Have an idea? Open an issue with the `enhancement` label.
