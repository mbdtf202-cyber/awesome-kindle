# Support

## Where to get help

This repo is an **index**, not a help desk — for hands-on jailbreak problems, the
official community is much faster and safer than opening an issue here.

| Need | Go to |
| --- | --- |
| Which jailbreak fits my model + firmware | [Jailbreak Wizard](https://kindlemodding.org/jailbreak-wizard.html) |
| Step-by-step jailbreak help | [KindleModding Discord](https://discord.kindlemodding.org/) |
| General chat / tweaks | [KindleTweaks Discord](https://discord.gg/yWPHHbrp7h) |
| Community Q&A | [r/kindlejailbreak](https://www.reddit.com/r/kindlejailbreak/) |
| Deep archive / old devices | [MobileRead](https://www.mobileread.com/forums/forumdisplay.php?f=150) |
| Official docs | [kindlemodding.org](https://kindlemodding.org/) |

## This repo's scope

- ✅ Corrections, new open-source resources, dead links, outdated firmware ranges
- ❌ Device-specific troubleshooting (ask the Discord instead)
- ❌ Piracy / shadow-library links (see the policy note in the README)

## Before you ask

1. Read the relevant [README section](../README.md) and the official wiki page in full.
2. Confirm your exact firmware under `Settings → Device Options → Device Info`.
3. Search the Discord / Reddit history — most questions are already answered.
