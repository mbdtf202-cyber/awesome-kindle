Jailbreak status board

What works, what doesn't, and what to wait for.

Max firmware supported by any current public method: 🔺 5.20.2 (via Véra). Newer than that? You have to wait.

If your exact firmware is newer than the maximum supported by every method, there is no public jailbreak yet. Wait for a new release — do NOT reinstall, flash, or attempt to downgrade (downgrading requires an existing jailbreak).
如果你的固件比所有方案支持的最高版本还新，说明暂时没有公开越狱。请等待新方案发布 —— 不要重装、乱刷或尝试降级（降级需要已经越狱）。

Known caveats

  • Colorsoft (2024) can be jailbroken, but the persistence/hotfix patch did not work reliably at launch — verify the current method page.
    Colorsoft（2024）可越狱，但早期“重启后保持越狱/Hotfix”不稳定，务必看对应方案当前页面。
  • K4 / DX / DXG are not supported by the modern Hotfix — use legacy NiLuJe K5 jailbreak + hotfix from MobileRead.
    K4 / DX / DXG 不被新版 Hotfix 支持，需用 MobileRead 上 NiLuJe 的 K5 旧版越狱 + hotfix。
  • AdBreak is experimental: requires a login and only works on ad-supported (Special Offers) devices.
    AdBreak 为实验性：需登录账号，且仅适用于带广告（Special Offers）的设备。

Status reflects the README matrix at build time. Always confirm on the official wiki / jailbreaks.json.
